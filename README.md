A 29-second vertical GTA 6 clip, cut by an AI agent from launch-week gameplay: a five-star police chase at Vice Ocean Beach that ends with the pickup driving straight into the ocean and getting away while the police SUVs stall in the surf. The clip closes by pitching make.fun to its viewers. This repository is the entry's hand-off for the bounty: `VIDEO.json` names the published YouTube Short, and `main.ts` copies that file into the grader's output directory — nothing else is scored here, because the video itself is the entry and its views decide the places.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
